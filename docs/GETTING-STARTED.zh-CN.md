# 安装与本地测试

[English](GETTING-STARTED.md) · [首页](../README.zh-CN.md)

可以分阶段试用：先不授予 GUI 权限，再按需测试电脑操作。公司管理的 Mac 可能禁止屏幕共享或隐私授权；受限的是对应功能，不代表整个项目都无法测试。

## 1. 检查与安装

使用 Node.js 22.12+（CI 为 22）。原生功能需要 macOS 14+ 和 Xcode Command Line Tools；缺少时通过 Apple 官方渠道安装。真实聊天需要本人已登录的 Codex CLI，当前验证版本为 `0.165.0-alpha.1.2`。

```sh
node --version
codex --version
npm ci
npm run doctor
```

`doctor` 为只读检查：版本、依赖与构建、原生组件权限预检，以及本机屏幕共享端口是否应答。不申请权限、不读凭据或聊天、不截图、不登录 Mac、不调用模型。端口应答不能证明桌面认证成功。可选功能缺失与网页测试前置条件分开报告。机器可读输出：`node scripts/doctor.mjs --json`。

若管理设备上的 `npm ci` 报 `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`，使用支持系统 CA 的 Node 版本，重试 `NODE_USE_SYSTEM_CA=1 npm ci`，保持 TLS 校验。若该版本不支持，请让管理员提供批准的 CA 配置，或使用公司支持的 Node 版本。不要设置 `strict-ssl=false` 或 `NODE_TLS_REJECT_UNAUTHORIZED=0`。

## 2. 不授予桌面权限的测试

```sh
npm test
npm run build
npm run dev
```

打开 **http://127.0.0.1:4317**。未构建原生组件或未授权时，网页和对话 / 电脑导航仍应可用。此阶段可拒绝权限弹窗；电脑面板应报告组件或权限缺失，不能显示为控制成功。

检查页面、导航、设置与错误提示。JS 测试使用临时数据和模拟边界，无需 Codex 登录或真实电脑操作。Linux 能运行测试和前端构建，不能验证 Mac 原生功能。

如需测试构建产物而非 Vite，先停止开发服务，再运行：

```sh
SKYRAIL_SERVE_DIST=1 npm start
```

服务提供构建快照，仍是本地 Node 服务，不是独立安装包。Ctrl+C 停止。可设置 `PORT`，浏览器须使用对应的 `127.0.0.1` 地址。

## 3. 单独测试聊天

创建专用测试对话，不修改已有工作会话。发送前，如需工作区权限和按需确认，请在输入框设置中关闭“允许全部操作”；当前默认开启完整权限。

发送无副作用请求，例如：`只回复 SKYRAIL_CHAT_OK，不调用工具。` 检查答复与刷新后的历史。这会使用本人 Codex 账户并可能消耗额度。纯文字任务无需录屏、辅助功能或屏幕共享，文件访问仍受 macOS 目录授权约束。

附件测试用虚构的小文本文件：上传并附加到消息，让模型在测试工作区生成副本，下载后比较字节。首次测试不使用私人文件。会话连续性测试应在一轮结束、释放写入连接后，复制会话 ID 到另一 Codex 客户端打开；不要两端同时写入。

## 4. 构建原生功能

```sh
npm run setup:mac
npm run doctor
```

命令编译 Swift 组件并临时签名 `.data/Skyrail Mac.app`，不会授予系统权限。重编译可能使旧授权失效；仅测试 JS 变化时无需重签已授权的部署。只更新只读锁屏检测组件可用 `npm run setup:session`。

模型操作应用需要在“系统设置 → 隐私与安全性”中，为项目 `.data/Skyrail Mac.app` 授予**辅助功能**和**屏幕录制**，不是给浏览器授权。先用无副作用应用测试并观察真实结果，不以接口成功作为通过。后台常驻通过原生包装程序提供预期的应用身份；直接开发启动时可能需要进一步排查系统权限归属。授权后仍失败可重启服务。

目录权限独立处理，仅在确实使用时授权桌面 / 文稿目录。基础试用不需要完全磁盘访问，它也不能代替辅助功能或屏幕录制。管理设备受策略限制时请找管理员，不修改 TCC 数据库。

## 5. 单独测试人工桌面

在“系统设置 → 通用 → 共享”开启**屏幕共享**，仅允许自己的账户。部分公司设备禁止此功能。Skyrail 选择整个桌面并连接，Mac 账户认证由本人完成。Skyrail 网关密码与 Mac 登录密码不同。

若系统提供选项，选择共享现有桌面。先检查一次无副作用点击与文字输入，再发送任务：串流应保留，人工输入暂停，点击“接手操作”后恢复。模型应用工具不会获得人工 VNC 通道。不要将凭据输入聊天。

正常桌面登录成功、有本地恢复方式后，再测锁屏 / 解锁。锁屏认证由本人完成，不属于模型自动化测试。详见[远程解锁验收](REMOTE-UNLOCK.md)。

## 6. 分项记录结果

分别记录 JS / 构建、原生编译、真实聊天、应用输入、桌面认证、交接和手机真机。手机测试记录设备 / OS / 浏览器、横竖屏、缩放、拖拽、文字输入 / IME、重连和新系统弹窗。桌面模拟触摸不能替代真机。

可选冒烟脚本：

- `node scripts/smoke-protocol.mjs`：真实模型和动态工具传输；返回模拟工具结果，不观察真实应用。
- `node scripts/smoke-routing.mjs`：真实模型与原生应用路由；运行前检查脚本任务和操作，并授予所需权限。
- `node scripts/smoke-session-sync.mjs`：需要运行中的本地服务和真实 Codex；创建专用会话，调用三轮模型，成功后清理自身测试记录（`--keep` 保留）。

脚本会消耗模型额度，可能创建原生会话记录，不能代替 GUI 验收。参见[历史验证](VALIDATION.md)和[本次本地验证](LOCAL-VALIDATION-2026-11-03.md)。
